# Forensic Biology & DNA

## Serology basics

Before DNA typing became standard, most biological evidence work was serological — identifying blood, semen, saliva by chemical/immunological tests, then typing by ABO. Presumptive vs confirmatory tests still matter for MCQs:

- **Kastle-Meyer** — presumptive test for blood (phenolphthalein).
- **Luminol** — presumptive; luminesces with residual blood, even after cleaning.
- **Teichmann / Takayama** — confirmatory crystal tests for haemoglobin.
- **Acid phosphatase** — presumptive for semen.
- **Phadebas / starch-iodine** — presumptive for saliva (alpha-amylase).

## From serology to DNA

DNA typing replaced serology as the definitive tool because it individualises rather than just narrowing to a blood group. The workflow:

1. **Extraction** — cells lysed, DNA freed from protein.
2. **Quantitation** — how much DNA do we actually have?
3. **Amplification** — PCR, targeting specific STR (short tandem repeat) loci.
4. **Separation & detection** — capillary electrophoresis; peaks at each locus.
5. **Interpretation** — profile called; matched against reference / database.

## STR loci and CODIS

Modern casework typically uses 15–20 STR loci plus amelogenin (sex marker). The FBI's CODIS system originally used 13 core loci; the expanded core is 20. India uses similar multiplex kits with an expanded set for improved match statistics.

## Mixtures

More than one contributor complicates every step of interpretation. Key concepts: number of contributors, major/minor contributors, stochastic thresholds, likelihood ratios.
